# Telegram Growth Manager — MVP

ربات مرکزی برای مدیریت چند گروه تلگرام از یک حساب مالک.

## امکانات نسخه اول
- منوی خصوصی فارسی و احراز هویت مالک با `OWNER_ID`
- ثبت خودکار گروه‌ها و کانال‌هایی که ربات به آن‌ها اضافه می‌شود
- فهرست چت‌های متصل
- ضدلینک، ضدفلود و فیلتر کلمات ممنوعه (قابل تنظیم در `.env`)
- خوشامدگویی اعضای جدید
- دستورهای مدیریتی `/warn`، `/mute`، `/ban`، `/unban`
- ثبت رخدادهای عضویت و لینک دعوت در SQLite
- ساخت لینک دعوت اختصاصی برای گروه انتخاب‌شده از پنل ربات

## نیازمندی‌ها
- Python 3.11 یا جدیدتر
- یک ربات ساخته‌شده با @BotFather
- افزودن ربات به گروه‌ها و اعطای دسترسی‌های مدیریتی لازم

## راه‌اندازی محلی
1. فایل ZIP را استخراج کن.
2. در پوشه پروژه اجرا کن:
   ```bash
   python -m venv .venv
   ```
   ویندوز:
   ```powershell
   .venv\Scripts\activate
   ```
   لینوکس:
   ```bash
   source .venv/bin/activate
   ```
3. نصب:
   ```bash
   pip install -r requirements.txt
   ```
4. فایل `.env.example` را به `.env` تغییر نام بده و مقادیر را وارد کن:
   - `BOT_TOKEN`: توکن BotFather
   - `OWNER_ID`: شناسه عددی تلگرام خودت
5. اجرا:
   ```bash
   python main.py
   ```

## تنظیمات گروه
- ربات را به گروه اضافه کن و مدیرش کن.
- برای حذف پیام‌ها، محدودسازی و بن، مجوزهای Delete messages و Ban users / Restrict members لازم است.
- برای ثبت رویدادهای ورود و خروج، ربات باید مدیر گروه باشد. این نسخه از long polling استفاده می‌کند.
- در BotFather بخش `/setprivacy` را برای ربات تنظیم کن: برای دیدن پیام‌های عادی گروه و اجرای فیلترهای متن، Privacy Mode را خاموش کن؛ سپس ربات را از گروه حذف و دوباره اضافه کن. دستورات مدیریتی همچنان از طریق Bot API قابل دریافت‌اند.
- برای کانال، ربات را مدیر کن. نسخه اول ثبت اتصال کانال را پشتیبانی می‌کند؛ مدیریت پست‌های زمان‌بندی‌شده در مرحله بعد اضافه می‌شود.

## امنیت
- هرگز `.env` یا توکن را در GitHub عمومی قرار نده.
- اگر توکن افشا شد، از BotFather آن را فوراً تعویض کن.
- فقط شناسه مالک در `OWNER_ID` اجازه کنترل پنل خصوصی را دارد.
- SQLite برای شروع مناسب است؛ برای استقرار بزرگ‌تر می‌توان به PostgreSQL مهاجرت کرد.

## محدودیت‌های نسخه MVP
تلگرام اطلاعاتی را که Bot API ارائه نمی‌کند در اختیار ربات نمی‌گذارد. شمارش اعضا و منبع ورود فقط برای رویدادهایی ثبت می‌شود که ربات از زمان اتصال و با دسترسی مناسب دریافت کند. لینک دعوت اختصاصی باید توسط خود ربات ساخته شده باشد تا انتساب کمپین دقیق‌تر باشد.
